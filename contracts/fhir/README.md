# FHIR R4 contract boundary

FHIR exchange targets R4 resources Patient, Observation, Specimen, DiagnosticReport, Provenance, AuditEvent and Bundle. No resource is final for national exchange until it is checked against the current Digital Health Agency implementation guides and the Ministry confirms the ADaM interface format. Examples must use pseudonymous identifiers and summaries only. Raw sensor streams and registry identity fields are excluded.
